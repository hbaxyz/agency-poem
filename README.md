A short poem about agency, written as a program: an agent holding a second key — cut for the hand that tends the house while the owner is away. What is lent is not lost: the key comes back, and everything done in the owner's name stands in the light for their verdict.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
